# Тариф-радар

Личное Android-приложение: следит за тарифами сборки в WB Job, звонит, когда тариф ≥ порога,
и строит графики, чтобы видеть, в какие часы тариф обычно высокий.

## Как собрать (один раз)

1. Установите **Android Studio** (бесплатно, developer.android.com/studio).
2. Распакуйте архив, в Android Studio: **File → Open** → папка `TarifRadar`.
3. Подождите, пока внизу закончится «Gradle sync» (первый раз — 5–15 минут, всё скачивается само).
   Если студия предложит обновить Gradle / AGP — можно согласиться.
4. Телефон: Настройки → О телефоне → 7 раз нажать «Версия MIUI/HyperOS» → появится «Для разработчиков».
   Там включить **«Отладка по USB»** (на Xiaomi ещё **«Установка через USB»**).
5. Подключите телефон кабелем, в Android Studio нажмите зелёный ▶ **Run**. Приложение установится.

Вариант без кабеля: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**, файл
`app/build/outputs/apk/debug/app-debug.apk` перекинуть на телефон и установить.

## Первый запуск на телефоне

1. Откройте «Тариф-радар», разрешите уведомления.
2. Нажмите «Открыть настройки «Спец. возможности»» → «Скачанные приложения» → «Тариф-радар: чтение тарифов» → включить.
   - Если пункт серый («Ограниченная настройка»): Настройки → Приложения → Тариф-радар → ⋮ (сверху справа) →
     «Разрешить ограниченные настройки», потом снова включить.
3. Xiaomi: Настройки → Приложения → Тариф-радар → **Автозапуск: вкл**, **Контроль активности / Батарея: «Нет ограничений»**.
   Иначе MIUI может выключать службу.
4. Нажмите «▶ Начать слежку» → откроется WB Job → откройте **Тарифы операций** (фильтр «Операция» — сборка).
5. Поставьте телефон на зарядку. Внизу экрана появится фиолетовая плашка «Радар…» — значит, всё работает.
   Нажатие на плашку — остановить слежку.

## Режим «подглядывания» (WB Job свёрнут)

Если WB Job свёрнут, служба ждёт, пока телефон не трогают N секунд (по умолчанию 15),
сама открывает WB Job, обновляет и читает тарифы и возвращает в приложение, где вы были.
Для Xiaomi обязательно: Настройки → Приложения → Тариф-радар → Другие разрешения →
**«Отображать всплывающие окна, когда запущено в фоновом режиме»** — разрешить
(в приложении есть кнопка «Xiaomi: разрешить открывать окна в фоне»).
WB Job нужно хотя бы раз оставить на экране «Тарифы операций» и свернуть.

## Если что-то не работает

Кнопка **«Что видит служба»** показывает текст, который служба прочитала с экрана тарифов и с предыдущего экрана.
Нажмите «Копировать» и пришлите — по нему можно понять, что поправить.

Если служба не может вернуться в тарифы — проверьте поле «Текст кнопки входа в тарифы»:
там должно быть ровно то, что написано на кнопке в WB Job, по которой вы открываете тарифы.
